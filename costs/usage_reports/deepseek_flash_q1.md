## 4. 要点与注意事项

1. **缓存是费用结构的主导因素**：prompt 中 98.95% 走缓存（$0.003/M），若按未命中价（$0.15/M）计费，本任务成本将是现在的约 12 倍。
2. **推理 token 是输出侧大头**：reasoning 占生成量 83.5%、占总费用 54.6%（与可见输出同价 $0.6/M）。
3. 统计口径说明：
   - `input` = 未命中缓存的 prompt 部分；`cache.read` = 命中缓存的部分；二者合计为真实 prompt；
   - `reasoning` 单独计入（不包含在 `output` 内），计费同 `output`；
   - `cost` 由 opencode 依据本地模型价目表自动计算，单位按 USD；
   - 子代理会话（explore）单独计费，已并入合计。
4. **快照数值会随后续对话继续增长**（每轮新调用都会增加 prompt/缓存/生成）；本报告已注明导出时刻。
5. 复现方法：查询 `opencode.db`（Python `sqlite3` 即可，`data` 为 JSON 文本）：
   ```sql
   -- session 表本身有汇总列（token 计数 + 成本）
   SELECT id,title,model,cost,tokens_input,tokens_output,tokens_reasoning,
          tokens_cache_read,tokens_cache_write
   FROM session WHERE id='ses_f50bb25fbffexCrr1ebXT0vrDr'
      OR parent_id='ses_f50bb25fbffexCrr1ebXT0vrDr';
   -- message 表逐条记录：data 字段内是 JSON（含 tokens 与 cost）
   SELECT id, session_id, data FROM message
   WHERE session_id='ses_f50bb25fbffexCrr1ebXT0vrDr' AND data LIKE '%"tokens"%';
   ```
   Python 侧用 `json.loads(data)["tokens"]` / `["cost"]` 逐条求和即可复现本报告全部数字。
