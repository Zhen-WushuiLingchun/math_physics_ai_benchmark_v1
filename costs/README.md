# 美元参考成本与用量来源

最终图表使用 [scores.csv](../data/scores.csv) 中参与者提供的三位小数美元记录，与[工作簿](../results/模型评分与成本汇总.xlsx)一致。24 项采用结果合计 **116.842 USD**；它是本次采用记录的参考成本合计，不是对订阅账户实际付款的审计。

[历史成本表](token_cost_01_02_03.md)按当时日志与 API 单价换算，保留原有高精度值、任务范围和排除项；[脱敏用量报告](usage_reports/README.md)覆盖其中一部分运行。部分记录为 API 等价美元成本，Grok 部分记录来自会话账本；这两类记录不能统一解释为账单实付。

原始评分表和新增金额由食司在整理阶段提供。新增的 GPT-6 Sol max 题 1 为 4.118，Luna max 题 1 为 0.178，DeepSeek Flash 三题为 0.414、0.430、0.477 USD。Opus 三题采用补充报告的评分并沿用 24.056、12.330、14.384 USD，各计一次。

已公开的日志没有覆盖 Astra 题 2/3、Sol max 题 2/3、Luna 题 2/3 的完整 token 细节；这些项目只列已提供费用，不反推出未记录的 token 数。不同统计范围、舍入和高精度金额可能造成与历史成本表逐项对账的差异。

本目录价格说明记录的是实验当时的换算口径，未重新核验当前官方价格。模型名称和推理档位按测试记录标注。
